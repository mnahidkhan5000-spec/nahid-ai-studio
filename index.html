Google Whisk-এ
আইডিয়াকে ছবি বানান।

Google-এর আসল Whisk ব্যবহার করতে নিচের বাটন চাপুন। এটি নতুন ট্যাবে খুলবে—আপনার এই স্টুডিও ও এখানকার কাজ খোলা থাকবে।

Google Whisk খুলুন

Google অ্যাকাউন্টে সাইন ইন করতে হতে পারে। দেশ, অ্যাকাউন্ট ও Google-এর শর্ত অনুযায়ী সুবিধা পাওয়া যাবে।

একটু আলাদা, দুটো কাজের জায়গা
  1. 1
    Whisk খুলুন

    Google-এর ওয়েবসাইট নতুন ট্যাবে খুলবে।

  2. 2
    ছবি ও নির্দেশনা দিন

    সেই ট্যাবেই Google Whisk দিয়ে কাজ করুন।

  3. 3
    ইচ্ছেমতো ফিরে আসুন

    এই ট্যাবে ফিরে নিজস্ব Image Studio ব্যবহার করুন।

এটি Whisk-এর শর্টকাট, অ্যাপের ভেতরে Google Whisk এমবেড করা হয়নি। দুই স্টুডিওর ছবি, অ্যাকাউন্ট ও ইতিহাস স্বয়ংক্রিয়ভাবে আদান-প্রদান হয় না।

02 / আপনার নিজস্ব IMAGE STUDIO

রেফারেন্স থেকে নতুন কিছু।

বিষয়, পরিবেশ আর স্টাইল মিলিয়ে নিজের ছবি বানান। এটি Google Whisk নয়—Gemini API-ভিত্তিক স্বাধীন একটি টুল।

সংযোগ পরীক্ষা হচ্ছে…
API সংযোগ ও সেটআপ সংযোগের অবস্থা দেখুন

সার্ভারের সংযোগ পরীক্ষা করা হচ্ছে।

ছবি তৈরি চালু করতে নিজের Node.js সার্ভারে .env ফাইলে GEMINI_API_KEY এবং আলাদা, কমপক্ষে ১৬ অক্ষরের STUDIO_ACCESS_TOKEN দিন। এরপর npm start দিয়ে সার্ভার চালু করুন। বিস্তারিত প্রকল্পের README.md ফাইলে আছে।

শুধু HTML ফাইল বা GitHub Pages দিয়ে এই API চলবে না। API key এখানে বা চ্যাটে দেবেন না। সেটআপ ছাড়াও রেফারেন্স সাজানো, প্রম্পট লেখা ও কপি করা যাবে।

Gemini-এর ব্যবহারমূল্য, quota, মডেল ও অঞ্চলের সীমা প্রযোজ্য হতে পারে। তৈরি ছবি রেফারেন্সের হুবহু কপি হওয়ার নিশ্চয়তা নেই।
